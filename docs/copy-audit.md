# Clear wording and uncluttered UI review

## Opening check

Reviewed main at `d866a02`. The stated audience can read Python lists, function calls and short loops. Averages and proportions help, and Scientific Method Lab is optional. Readers should be able to follow the causal argument and make the specified edit without knowing statistical jargon, matrix operators or plotting libraries first.

Read the overview, all six module entries, the course notes and glossary, all 18 investigations, every original code listing and printed result, the five plot descriptions, all 18 concept panels, and the course illustration. For each investigation, checked the title and goal, explanation, prediction, run instructions, output labels, suggested edit, limits, fresh question, options, hints, answer feedback and source. Checked shared control labels, accessibility names, help, absence of a result, loading, running, Stop, errors, successful runs, saved drafts, restore/recover, reading marks, exports and report fields. Followed the baseline workbench and reproduced the storage-denied notes claim and empty progress export independently.

The opening pass checked that each sentence served context, explanation, preparation, a learner action or result interpretation. It also checked that actions targeted the editable code, comparisons named visible evidence, necessary terms appeared before use, and claims matched the model. The workbench check looked for a visible path through prediction, preparation, execution, results, interpretation and the edit, with diagnostics and exports available on demand.

### Functional verification

`npm run check` covers seven native numerical-contract groups, the 18 build executions, the static links and the Chromium workbench checks. The browser walkthrough uses the unchanged editor on every lesson's own route and runs each literal documented edit. It also checks every fresh question, dark mobile layout, draft recovery, import/export, denied storage, errors and keyboard interaction. The preview was checked manually at 320, 390, 768 and 1440 CSS pixels.

### Learning effectiveness

The review checks wording, interface behaviour and model calculations. It does not measure whether learners can choose a causal design or explain the examples independently. No novice study or assistive-technology user study was conducted.
