Before you start

You should be able to read Python lists, function calls and short loops. Knowing how to calculate a mean and a proportion will help. The lessons introduce the causal and statistical concepts as you need them.

Start with lesson 1 and work through the 18 lessons in order. Plan for about eight minutes per lesson plus any time you spend exploring. The editor already contains a complete example. Make a prediction, run the code, inspect the named results, then try the suggested edit and the new question.

Scientific Method Lab is optional preparation if you want to practise designing comparisons and interpreting uncertainty. Here you ask what treatment changes using examples of data collected without assigning the treatment.

The lessons use invented values or simulations. These examples can reveal quantities real studies rarely know, such as what the same person would score with and without treatment. They illustrate how a method works and what assumptions it needs.

Running Python

Select Run Python to execute the exact code in the editor. Python and its packages can load while you read. Keep a connection until they load. Ctrl+Enter or ⌘+Enter also runs Python from the editor. Tab moves to the next control.

Select Stop to cancel a run. The next run starts a new Python session. The page stops waiting after two minutes of loading or 45 seconds of execution. An error appears below the editor and any earlier successful result stays visible.

Open Published example output to see the original code's result from the site build, even with JavaScript disabled. Your result appears only after a successful browser run. The site identifies whether a run used published or edited code and flags subsequent edits. Floating-point formatting and results from random draws can vary between Python environments.

Keep your work

The course saves code, predictions, notes, checked answers, report fields and reading marks in this browser when storage is available. Reading marks show where you left off. Clearing the site's data removes these saved items.

In Editor tools, Restore example opens the published code and keeps one previous draft for Recover draft. Download Python saves the current editor contents to a file, even if the browser cannot save drafts.

On the course overview, open Save or restore your work and choose Export progress & drafts for a portable copy of your saved items. Import progress replaces matching records in this browser. Export first if you want to keep both versions.

After a successful run, open Run exports and choose Download run JSON to save the exact code, output, plots and runtime versions. The last successful run is kept only while the page is open. The final lesson also offers Export causal report for your report fields and the code and text output from that lesson's last successful run.

Python packages and device behaviour

The site runs Pyodide 0.27.7 in a browser worker. Each run starts with fresh user variables and reuses loaded modules. NumPy, SciPy, pandas and Matplotlib are pinned and their package files are checked at build time. See the browser runtime manifest or the site build environment.

The lab runs your code locally and stores drafts in this browser. Code you edit or paste can make network requests that the browser permits. Use code that you trust. The lab needs a connection for assets the browser has not cached. If you prefer running Python locally, the repository supplies the examples and package requirements.

Key terms

Estimand
The precise effect you want to estimate, including whose effect, which treatment choices, which outcome and when it is measured.
Identification
Expressing the causal effect of interest using observed information and stated assumptions.
Exchangeability
The treatment groups are comparable in their potential outcomes, possibly after accounting for characteristics measured before treatment.
Consistency
The outcome observed for a person matches the potential outcome for the specific treatment choice they received.
Positivity
Each treatment choice has some chance of occurring in each group needed for the comparison.
No interference
One person's outcome depends on their own treatment choice independently of anyone else's treatment choice.
Confounder
A cause shared by treatment and outcome.
Mediator
A step through which treatment affects the outcome.
Collider
A common effect of two variables along a path.
ATE
Average treatment effect in the target population.
ATT
Average treatment effect among the treated.
LATE
Local average treatment effect. In the invitation example, it is the average effect for people who attend only if invited, under the instrumental-variable assumptions.
